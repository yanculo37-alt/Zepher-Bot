# Minecraft Realm Bot
A powerful Discord bot designed to connect to and interact with Minecraft Bedrock Realms.
The bot provides tools for Realm management, monitoring, player utilities, and other Realm-related features through Discord.
Features
* Connect to Minecraft Bedrock Realms
* Join Realms using a Realm Code or Realm ID
* Player and gamertag utilities
* Realm information and monitoring
* Minecraft <-> Discord communication
* Realm management tools
* Player/position logging
* Fast and lightweight
* Account authentication support
* Discord slash commands
* Modular command system
Requirements
* Node.js 20+
* A Discord Bot
* A Minecraft Bedrock account
* MongoDB or another supported database, if enabled by your configuration
